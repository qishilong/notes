方案 G: CSP script-src 'none' — 阻止 JS 执行，保留 HTML 渲染

原理：在 iframe 的 srcdoc 中注入 <meta http-equiv="Content-Security-Policy" content="...">， 浏览器级别禁止所有 JavaScript 执行。HTML / CSS 正常渲染，图片正常加载。
基础 CSP 策略：script-src 'none'
效果：禁止所有 inline script、外部 script、on* 事件、javascript: 协议、eval()。
HTML 和 CSS 正常渲染，图片正常加载。

增强 CSP 策略：
script-src 'none'; object-src 'none'; frame-src 'none'; base-uri 'none'; form-action 'none'; style-src 'self' 'unsafe-inline'
在基础 CSP 之上，额外禁止：嵌套 iframe、object/embed 插件、form 提交、base 标签劫持。

⚠️ 边界 Case — CSP 方案的局限性：
CSP 只管 JS 执行，以下攻击向量不在 CSP 的管辖范围内。
